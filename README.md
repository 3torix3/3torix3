## How I build

- **HTTP-first and lean.** Browsers only when unavoidable, so runs stay fast and cheap: thousands of rows per minute on 512 MB.
- **Fair pricing.** You pay per delivered result. Failed pages, duplicates and filtered rows are free, and spending limits are respected exactly.
- **AI-native output.** Stable schemas, Markdown text, token counts and content hashes, so data drops straight into RAG and agents.
- **Tested and benchmarked.** Unit tests on parsers and real platform runs before every release.
